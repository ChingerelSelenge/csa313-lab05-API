## Даалгавар 2
**Тестлэгдэх функц:** `POST /registrations` 
POST /registrations нь оюутныг хичээлд бүртгэнэ.
Тестээр HTTP статус болон хариуны result утгыг шалгана.
 
## Эквивалент анги ба тестийн өгөгдөл

| Сонголт | Эквивалент анги | Төлөөлөх утга |
|---|---|---|
| Оюутны төлөв | Байгаа, идэвхтэй | `status: "active"` |
| Оюутны төлөв | Байгаа, идэвхгүй | `status: "inactive"` |
| Оюутны төлөв | Байхгүй | Setup-аар үүсгээгүй ID |
| Үзсэн хичээлүүд | Бүх урьдачийг хангана | `["CS201", "CS202"]` |
| Үзсэн хичээлүүд | Урьдачийг огт хангахгүй | `[]` |
| Үзсэн хичээлүүд | Зарим урьдачийг хангана | `["CS201"]`, харин урьдач нь `["CS201", "CS202"]` |
| Хичээлийн хүчинтэй байдал | Байгаа | `PUT`-ээр үүсгэсэн хичээл |
| Хичээлийн хүчинтэй байдал | Байхгүй | Setup-аар үүсгээгүй хичээлийн код |
| Хичээлийн урьдач нөхцөл | Урьдачгүй | `prerequisites: []` |
| Хичээлийн урьдач нөхцөл | Нэг урьдачтай | `["CS201"]` |
| Хичээлийн урьдач нөхцөл | Олон урьдачтай | `["CS201", "CS202"]` |
| Хүсэлтийн талбар | Хоёр талбар бүрэн | `studentID`, `courseID` хоёул байна |
| Хүсэлтийн талбар | Талбар дутуу | `courseID` байхгүй |
| JSON формат | Зөв | Хүчинтэй JSON |
| JSON формат | Буруу | Хаалтын `}` дутуу |
 
**Спецификацийн хүснэгт:**

| № | Ангилал | Тайлбар | Оролт / нөхцөл | HTTP статус | Хүлээгдэж буй `result` |
|---:|---|---|---|---:|---|
| 1 | Happy path | Идэвхтэй, CS201 үзсэн оюутан CS313-д бүртгүүлнэ | `studentID=B231234567`, `courseID=CS313`; оюутан идэвхтэй, `coursesTaken` нь `CS201` агуулна | 201 | `OK` |
| 2 | Алдааны анги | Оюутан байхгүй | Бүртгэлгүй `studentID`, хүчинтэй `courseID` | 200 | `ERROR_NO_STUDENT` |
| 3 | Алдааны анги | Оюутан идэвхгүй | `status="inactive"` | 200 | `ERROR_INACTIVE_STUDENT` |
| 4 | Алдааны анги | Хичээл байхгүй | Бүртгэлгүй `courseID`, хүчинтэй `studentID` | 200 | `ERROR_NO_COURSE` |
| 5 | Алдааны анги | Урьдач нөхцөл огт дутуу | `coursesTaken=[]`, `prerequisites=["CS201"]` | 200 | `ERROR_PREREQUISITES`, `missing=["CS201"]` |
| 6 | Давхар алдаа | Оюутан ч, хичээл ч байхгүй | `studentID=NOBODY`, `courseID=NOCOURSE` | 200 | `ERROR_NO_STUDENT` |
| 7 | Давхар алдаа | Идэвхгүй оюутан + байхгүй хичээл | `studentID=INACT1` (`inactive`), `courseID=NOCOURSE` | 200 | `ERROR_INACTIVE_STUDENT` |
| 8 | Хязгаар | Урьдач нөхцөлгүй хичээл | `prerequisites=[]`; бусад нөхцөл хүчинтэй | 201 | `OK` |
| 9 | Хязгаар | Зарим урьдач л хангагдсан | `prerequisites=["CS201","CS202"]`, `coursesTaken=["CS201"]` | 200 | `ERROR_PREREQUISITES`, `missing=["CS202"]` |
| 10 | Хязгаар | `studentID` талбар дутуу | Body-д зөвхөн `courseID` байна | 400 | `ERROR_BAD_REQUEST` |
| 11 | Хязгаар | `courseID` талбар дутуу | Body-д зөвхөн `studentID` байна | 400 | `ERROR_BAD_REQUEST` |
| 12 | Хязгаар | Буруу JSON | Синтаксийн хувьд эвдэрсэн JSON body | 400 | `ERROR_BAD_JSON` |
