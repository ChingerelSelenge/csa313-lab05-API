## Даалгавар 2

**Тестлэгдэх функц:** `POST /registrations` 
POST /registrations нь оюутныг хичээлд бүртгэнэ.
Тестээр HTTP статус болон хариуны result утгыг шалгана.
 
**Эквивалент анги ба тестийн өгөгдөл**

| Сонголт | Эквивалент анги | Төлөөлөх утга |
|---|---|---|
| Оюутны төлөв | Байгаа, идэвхтэй | `status: "active"` |
| Оюутны төлөв | Байгаа, идэвхгүй | `status: "inactive"` |
| Оюутны төлөв | Байхгүй | Setup-аар үүсгээгүй ID |
| Үзсэн хичээлүүд | Бүх урьдачийг хангана | `["CS201", "CS202"]` |
| Үзсэн хичээлүүд | Урьдачийг огт хангахгүй | `[]` |
| Үзсэн хичээлүүд | Зарим урьдачийг хангана | `["CS201"]`, харин урьдач нь `["CS201", "CS202"]` |
| Хичээлийн хүчинтэй байдал | Байгаа | `PUT`-ээр үүсгэсэн хичээл |
| Хичээлийн хүчинтэй байдал | Байхгүй | Setup-аар үүсгээгүй хичээлийн код |
| Хичээлийн урьдач нөхцөл | Урьдачгүй | `prerequisites: []` |
| Хичээлийн урьдач нөхцөл | Нэг урьдачтай | `["CS201"]` |
| Хичээлийн урьдач нөхцөл | Олон урьдачтай | `["CS201", "CS202"]` |
| Хүсэлтийн талбар | Хоёр талбар бүрэн | `studentID`, `courseID` хоёул байна |
| Хүсэлтийн талбар | Талбар дутуу | `courseID` байхгүй |
| JSON формат | Зөв | Хүчинтэй JSON |
| JSON формат | Буруу | Хаалтын `}` дутуу |
| Setup-ийн сонголтот талбарууд | Талбаруудыг орхисон | Оюутан болон хичээлийн setup-д {} | 
 
**Спецификацийн хүснэгт:**

| ID   | Нөхцөл                                         | Хүлээгдэх статус | Хүлээгдэх `result`       |
| ---- | ---------------------------------------------- | ---------------: | ------------------------ |
| TC01 | Идэвхтэй оюутан, байгаа хичээл, урьдач бүрэн   |              201 | `OK`                     |
| TC02 | Оюутан байхгүй, хичээл байгаа                  |              200 | `ERROR_NO_STUDENT`       |
| TC03 | Оюутан идэвхгүй, хичээл байгаа, урьдач хангана |              200 | `ERROR_INACTIVE_STUDENT` |
| TC04 | Оюутан идэвхтэй, хичээл байхгүй                |              200 | `ERROR_NO_COURSE`        |
| TC05 | Оюутан идэвхтэй, нэг урьдач дутуу              |              200 | `ERROR_PREREQUISITES`    |
| TC06 | Оюутан болон хичээл хоёул байхгүй              |              200 |  `ERROR_NO_STUDENT`     |
| TC07 | Оюутан идэвхгүй, хичээл байхгүй                |              200 | `ERROR_INACTIVE_STUDENT`      |
| TC08 | Урьдачгүй хичээл, үзсэн хичээлгүй оюутан       |              201 | `OK`                     |
| TC09 | Хоёр урьдачаас нэгийг үзсэн                    |              200 | `ERROR_PREREQUISITES`    |
| TC10 | `courseID` талбар дутуу                        |              400 | `ERROR_BAD_REQUEST`      |
| TC11 | Буруу JSON                                     |              400 | `ERROR_BAD_JSON`         |
| TC12 | Setup-ийн сонголтот талбаруудыг орхисон        |              201 | `OK`                     |
